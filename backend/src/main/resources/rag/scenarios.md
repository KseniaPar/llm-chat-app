# Сценарии RAG-чата (День 25)

Корпус: **«Основы православия»**. Каждый сценарий — 12–14 реплик пользователя для проверки: цель не теряется, sources/quotes в каждом ответе, уточнения попадают в task memory.

---

## Сценарий 1: Подготовка к экзамену по таинствам

**Цель диалога:** систематически разобрать семь Таинств для устного экзамена.

| # | Роль | Сообщение |
|---|------|-----------|
| 1 | user | Привет! Готовлюсь к экзамену по «Основам православия». Хочу разобрать все семь Таинств — по одному за раз, с определениями. |
| 2 | user | Начнём с Крещения. Что это за таинство и когда оно было установлено? |
| 3 | user | А какие условия нужны для действительного Крещения? |
| 4 | user | Спасибо. Теперь Миропомазание — чем оно отличается от Крещения? |
| 5 | user | Запомни: на экзамене меня могут спросить именно про «печать» Духа Святого. |
| 6 | user | Перейдём к Покаянию. Какие ступени покаяния ты знаешь из учебника? |
| 7 | user | А что такое епитимия и когда её назначают? |
| 8 | user | Дальше Евхаристия — это самое важное для меня. Расскажи кратко смысл и когда установлено. |
| 9 | user | Что означает слово «Евхаристия» и как правильно называть Причащение? |
| 10 | user | Теперь Брак и Священство — по очереди, коротко. |
| 11 | user | И последнее — Елеосвящение. Для кого это таинство и как его ещё называют? |
| 12 | user | Подведи итог: перечисли все семь Таинств одной строкой, как на экзамене. |
| 13 | user | Какая у нас была цель этого диалога? Проверь, что мы всё прошли. |

**Ожидаемая task memory:**
- `dialogGoal`: подготовка к экзамену по семи Таинствам
- `clarifications`: по одному таинству за раз; акцент на Евхаристии; вопрос про «печать» на экзамене
- `fixedTerms`: семь Таинств, Крещение, Миропомазание, Покаяние, Евхаристия, Брак, Священство, Елеосвящение

## Сценарий 2: Разбор Символа веры и христологии

**Цель диалога:** понять первые члены Символа веры и ключевые догматы о Христе.

| # | Роль | Сообщение |
|---|------|-----------|
| 1 | user | Здравствуй. Мне нужно разобрать Символ веры для контрольной — только первые четыре члена, без спешки. |
| 2 | user | Что означает «Верую во Единого Бога Отца»? Кратко, по учебнику. |
| 3 | user | Объясни второй член — про Сына Божия и Боговоплощение. |
| 4 | user | Уточни: меня интересует именно две природы во Христе, без ереси. |
| 5 | user | Третий член — про Распятие и Воскресение. Что такое искупление? |
| 6 | user | А четвёртый член — Вознесение и Страшный Суд. Что там главное? |
| 7 | user | Запомни термин: «Филиокве» — его могут спросить отдельно, но сейчас не углубляйся. |
| 8 | user | Вернись ко второму члену: когда и где родился Христос по учебнику? |
| 9 | user | Связь с Ветхим Заветом: какое пророчество о Рождестве упоминается? |
| 10 | user | Сравни: что общего у Боговоплощения и таинства Евхаристии? |
| 11 | user | Я запутался в словах «искупление» и «искупительная жертва» — в чём разница по тексту? |
| 12 | user | Сформулируй для меня краткий конспект четырёх членов — по одному предложению. |
| 13 | user | Проверь: мы разобрали все четыре члена, которые я просил в начале? |
| 14 | user | Какие термины мы зафиксировали за этот диалог? |

**Ожидаемая task memory:**
- `dialogGoal`: разбор первых четырёх членов Символа веры для контрольной
- `clarifications`: без спешки; акцент на двух природах Христа; Филиокве — отдельный термин на потом
- `fixedTerms`: Символ веры, Боговоплощение, искупление, две природы, Филиокве

## Как прогонять

1. Открыть UI «День 25 — RAG Chat».
2. Нажать «Новый диалог» (сброс session).
3. Вводить сообщения пользователя из таблицы по порядку.
4. После каждого ответа проверять: sources ≥ 1, quotes ≥ 1 (кроме off-topic), панель task memory обновляется.
5. На финальном сообщении — цель и термины сохранены в sidebar.
